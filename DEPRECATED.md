# ⚠️ bmad-assist is deprecated (end-of-life)

**Status:** No longer maintained — as of 2026-06-07
**Final version:** v0.4.34
**Successor:** [bmad-automator](https://github.com/bmad-code-org/bmad-automator)

---

## Why is this project ending?

**bmad-assist** was a solo-maintained project, built against **BMAD v6.0.0-alpha.22** —
an early alpha release. It still works with that version, but BMAD has moved on, and
keeping a single-person tool in sync with every new release is no longer sustainable or
sensible.

A better path forward already exists.

## What should I use instead?

### 👉 [bmad-automator](https://github.com/bmad-code-org/bmad-automator)

The spiritual successor to bmad-assist:

- **Skills-based** architecture instead of bundled, compiled workflows
- **Community-maintained** — developed openly by the BMAD community, not a single person
- **Compatible with the latest BMAD versions**, not pinned to v6.x

If you're starting a new project or migrating an existing one, use **bmad-automator**.

## What happens to this repository?

- It **stays online** as a reference and a record of the work.
- It remains **open** for now — existing forks, issues, and pull requests are not blocked.
- It is **read-only in spirit**: no new features, fixes, or releases are planned.
- The repository may be formally **archived** (made read-only) at a later date.

## Does it still work?

Yes — bmad-assist continues to function with **BMAD v6.0.0-alpha.22**. If you have an
existing setup pinned to that version, nothing breaks. But there will be no further updates, so
plan your migration to [bmad-automator](https://github.com/bmad-code-org/bmad-automator)
accordingly.
